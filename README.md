# 缺貨罰款分析 Dashboard Demo

這是一個以作品集展示為目的的 **缺貨罰款分析 Dashboard Demo**。  
專案模擬企業在通路缺貨、罰款、申訴與原因追蹤上的資料分析流程，透過網頁儀表板將原本分散在表格中的資料轉換為可視化管理工具，協助使用者快速掌握高風險通路、品項與改善方向。

> 本版本為 Demo 版，所有資料皆已匿名化與模擬處理，不包含任何機密資訊。

---

## 專案目標

在實際工作情境中，缺貨罰款資料通常分散於試算表、人工紀錄與不同單位回填內容中，主管或執行人員需要花費大量時間整理、比對與判讀。

本 Demo 目標是展示如何透過前端 Dashboard：

- 將缺貨與罰款資料集中呈現
- 快速篩選年度、月份、通路與品類
- 找出最主要的罰款來源
- 彙整原因說明與改善方向
- 產出可供檢視的分析摘要
- 匯出明細資料供後續追蹤

---

## Demo 特色

### 1. KPI 年度比較

Dashboard 提供年度 A / 年度 B 的金額比較，包含：

- 預估缺罰
- 通路應罰
- 實際缺罰
- 免罰申訴
- 最終缺罰

透過成長率與狀態標籤，快速判斷罰款風險是否上升或下降。

---

### 2. 多條件篩選

支援依照以下條件切換資料視角：

- 年度
- 月份
- 通路
- 利潤中心 / 品類
- 顯示模式
- 樞紐維度

使用者可以從總覽快速下鑽到特定月份、通路或品類。

---

### 3. 樞紐摘要表

可切換不同分析維度，例如：

- 依通路分析
- 依品類 / 利潤中心分析

並提供：

- 年度比較
- 成長率
- 缺貨金額占比
- 風險狀態判斷

---

### 4. Top 10 圖表

以圖表方式呈現主要風險來源：

- Top 10 通路最終缺罰排行
- Top 10 品類最終缺罰排行

協助快速找出需要優先處理的對象。

---

### 5. 原因說明彙整

系統會根據 Demo 資料中的原因欄位，彙整主要缺貨原因與影響品項。

---

### 6. AI 分析 Prompt / Demo AI 分析

此 Demo 保留 AI 分析展示流程：

- 產生 AI 分析 Prompt
- 模擬 AI 分析結果
- 彙整主要原因
- 提供主管視角的行動建議
- 產出摘要結論

> Demo 版不串接真實任何 AI API。

---

### 7. Excel 匯出

可匯出目前 Dashboard 中的 Demo 資料，包含：

- 匯出說明
- KPI 年度比較
- 樞紐摘要
- 明細資料
- Top 10 明細
- 原因說明彙整

---

## 技術架構

本 Demo 為純靜態網頁版本，僅作為作品集展示。

使用技術：

- HTML
- CSS
- JavaScript
- Chart.js
- SheetJS / XLSX

Demo 版特色：

- 不需要後端
- 不需要登入
- 不串接 Google Sheets
- 不串接 Apps Script
- 不使用 API Key
- 可直接部署於 GitHub Pages 或 Cloudflare Pages
